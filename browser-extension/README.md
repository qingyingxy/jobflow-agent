# JobFlow 官网跟进

首次连接（Chrome 或 Edge 桌面版）：

1. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式。
2. 点击“加载已解压的扩展程序”，选择本文件所在的 `browser-extension` 文件夹。
3. 在同一个浏览器中打开 `http://localhost:3000`，刷新页面。
4. 进入“追踪动态 → 投递跟进 → 官网申请进度”，添加同程个人页链接，点击“一键同步”。
5. 若出现登录页，自行登录同程后回到 JobFlow，再点“一键同步”。

每次同步会临时打开同程申请页，读取所有分页并关闭临时页面。登录失效时保留登录页，等待本人操作。支持的地址为 `https://mhr.ly.com/recruit/schoolPortal/#/personal`。其他网站尚未适配。

扩展仅从同程“我的申请”表格读取岗位名称、招聘类型、地点、投递时间、投递状态，并传回本机 JobFlow。不会读取密码、Cookie、手机号、邮箱、简历，也不调用大模型。只自动点击申请表格的“下一页”，不投递、撤回或预约面试。

浏览器安装时会请求同程网站读取权限。本机 JobFlow 必须与扩展处于同一个浏览器；Codex 内置浏览器的登录态不会迁移到 Chrome/Edge。此版本是手动触发的一键同步，未启用后台定时读取。删除扩展可撤销网站访问权限，已同步记录仍保存在本机数据库。
